Лабораторна робота 6 — сопрограми C++20, варіант 7

Тракалюк Анжеліка, К-28

Сопрограма генерує випадкові числа з [1, 256]. Для парних чисел контролер очікування передає керування сопрограмі A, яка виводить число; для непарних генератор продовжує роботу.

Формат вхідних даних

Один рядок зі стандартного входу: ціле число від 1 до 1000 — кількість чисел для генерації. Пробіли навколо числа дозволені.
Некоректний ввід (не число, зайві символи після числа, число поза межами) — програма виводить повідомлення про помилку і завершує роботу.
